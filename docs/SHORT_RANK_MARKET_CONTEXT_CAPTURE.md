# Prospective original SHORT coarse-rank market context

The existing SHA-sealed original rank/full-feature suffix is still **conditional on the producer's declared rankable universe**. The original market metadata, all four price checks, source receive clocks and context freshness that the production `evaluate_eligibility` used were not saved at those earlier rank refreshes.

This change begins an additional **first-seen, append-only eligibility context suffix** at the next paper-worker adoption. At exactly the same original coarse rank refresh and observed clock, the worker captures the matching `PerpMarketSnapshot` for **every originally featured coarse-universe market**, not just the ranked winners. It preserves the exact metadata, context Decimal strings, price fields, mainnet-source claim, source receipt clock and source schema. Every canonical batch is hashed and bound to the unmodified rank snapshot digest, capture time, feature-market population and receive clocks.

The read-only replay joins a rank, its complete original feature batch and a matching original market context batch. It re-runs the actual broad feature construction and `evaluate_eligibility` with original default quantile thresholds. It **rejects** a modified delisting status, leverage, price state, stale context, missing featured market or changed source feature identity. The original ranked-market set must match the reconstructed rankable membership exactly. This is not a retroactive reinterpretation of the older ID-only or full-feature-only rank history.

Each context file is fsync'd and hardlinked into place without overwriting an existing batch. Missing, corrupt, reordered, rewritten or backdated records fail closed, and research capture/restore errors create permanent no-execution/no-promotion receipts. This suffix lives in `prospective-short-rank-market-context/`, separately from the original paper journal and actual market/risk pipeline. The trader still uses the unchanged production features and decisions; the context recorder only observes them after the rank has already been calculated.

**Boundary:** A locally captured original context is still just producer-reported source. It is **not independently GitHub artifact attested** and does not prove genuine external Hyperliquid feed origin, complete market-data gap coverage or capital-matched after-fee full-account positive expectancy. A separate original-worker post-exit sealed archive, strict authenticated GitHub source binding and independent replay over that artifact are the next required steps. The old immutable full-feature-only suffix remains permanently without market contexts. Frozen v5 losses, risk budgets, stops and LIVE=false are unchanged.
